# Memory Skill

每次当对话结束后，通过整理这几次对话的内容，更新一个talk_summary.md文件。这个文件的内容是这几次对话的总结。同时丢弃大量的上下文信息。如果对某一个信息不清楚的时候，通过读取talk_summary.md文件来获取信息。

## 对话总结

对话总结的格式如下：

```
这次对话主要讨论了主要问题是：{问题}
问题的结论是{结论}

这次对话主要讨论了主要问题是：{问题}
问题的结论是{结论}

```
